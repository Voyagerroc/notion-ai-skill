# CLAUDE.md - Claude Code Integration Guide

This file provides instructions for **Claude Code** when working in repositories equipped with the `notion-ai` hybrid skill.

---

## 🎯 Purpose

When performing large-scale code synthesis, architectural planning, file refactoring, or heavy reasoning tasks where you want to conserve Anthropic Claude API tokens, delegate the generation to the local **Notion AI Bridge** (`notion-ai`).

* **Token Consumption:** Billed directly to Notion AI ($0 marginal API cost).
* **Model Selection:** Claude 3.5 Sonnet / 4.6 / 5, Claude Opus, GPT-5.5, Kimi K2.7/K3, DeepSeek V4.
* **Execution:** Claude Code reads files locally, passes context to `notion-ai`, extracts code, and runs tests.

---

## 🔐 Authentication & Session Lifecycle

Before dispatching tasks to Notion AI:
1. Verify connection status: `voyager-relay whoami`
2. If unauthenticated, tell the user to run `voyager-relay login` in their local terminal.
3. **NEVER ask the user to paste `token_v2` or passwords into the Claude Code conversation.**

---

## 💻 Claude Code Commands

Use the `Bash` tool to run the following patterns:

### 1. Code Generation & Analysis (Claude Sonnet via Notion AI)
```bash
notion-ai -m sonnet "Refactor the authentication middleware to support JWT refresh tokens"
```

### 2. Multi-File Context Feeding
```bash
notion-ai -m sonnet -f app/server.py -f app/auth.py "Identify security bottlenecks between these modules"
```

### 3. Large Context via File (-P / --prompt-file)
When prompt and code exceed shell length limits:
```bash
# 1. Write prompt to temporary file
echo "Analyze the following schema..." > /tmp/prompt.txt
cat schema.sql >> /tmp/prompt.txt

# 2. Invoke Notion AI
notion-ai -m sonnet -P /tmp/prompt.txt
```

### 4. Direct Safe AST Code Patching
```bash
notion-ai -e target_file.py -y "Add type hints and docstrings"
```

### 5. Using Kimi (Moonshot AI) for Extended Context
```bash
notion-ai -m kimi "Analyze this multi-turn architecture workflow"
```

---

## 🛡️ Best Practices for Claude Code
1. Always run local tests (`pytest`, `npm test`) after applying changes generated by Notion AI.
2. If Notion AI output needs adjustments, run `notion-ai --rollback <file>` or apply edits directly with Claude Code's file edit tools.
3. For interactive sessions, invoke `notion-ai` without arguments in terminal.
